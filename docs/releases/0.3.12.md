# KeyDock 0.3.12

KeyDock switches Windows keyboard layouts when you connect or disconnect an external keyboard. For example, keep Russian and Spanish on your laptop and switch to Russian and US English when a US keyboard is connected.

- Set laptop and external profiles in Settings, with support for USB and Bluetooth keyboards, multiple devices and manual classification.
- Use the tray to pause switching, reapply a profile or configure Start with Windows.
- Save notification and timing changes without turning an unconfigured mode into a new profile.

Download the **x64 MSI** for installation or the **x64 ZIP** to run KeyDock from a folder of your choice. Download the matching notices ZIP with the MSI. The portable ZIP includes its notices. The release includes `SHA256SUMS.txt`. Compare the download's hash using `Get-FileHash -Algorithm SHA256`.

The x64 candidate completed desktop and installer validation on a Windows 10 22H2 console VM, including an upgrade from a running 0.3.9 tray. Dock and resume events were simulated. Windows 11 final validation was waived. ARM64 native validation is pending.

Windows may reorder the preferred languages or remove a language when its last layout is removed. Some applications, including elevated windows, may ignore focus-window switch requests.
