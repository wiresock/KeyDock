## MSI resources

The MSI embeds unmodified WiX UI resources and WiX Util custom actions from WiX Toolset 6.0.2, copyright .NET Foundation and contributors. They are distributed under the [Microsoft Reciprocal License](notices/wix/LICENSE.TXT). The matching [WiX 6.0.2 source](https://github.com/wixtoolset/wix/tree/b3f340393117094a75ea8ced77f2357e4aa095e7) is available as an [archive](https://github.com/wixtoolset/wix/archive/b3f340393117094a75ea8ced77f2357e4aa095e7.tar.gz). Distribute the MSI with its matching notices archive. WiX's precompiled NuGet tools have separate [build-use terms](https://docs.firegiant.com/wix/osmf/).

Project tray icons are generated by `tools/make_icons.py` using drawing primitives. Pillow is an icon-generation tool. Application assets are the resulting icons.
